# Panora

**[📊 Full Presentation Slides](https://drive.google.com/file/d/14fIG9k03dRO-YtHq5xYs_pkcrYbjpXv1/view?usp=sharing)**
**[🎥 Demo Video](https://drive.google.com/file/d/1P199xDTNFxECVWvonUDtL_Yd1DTnpnaz/view?usp=sharing)**

Panora is a desktop application foundation for creating panoramic images from multiple photographs. It is being developed incrementally with Electron, React, Vite, Adobe React Spectrum, and OpenCV.js.
